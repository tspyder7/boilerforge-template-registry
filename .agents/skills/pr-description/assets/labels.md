# Supported PR Labels

Use only these labels when proposing labels for a PR. One `type:*`, one `status:*`, and one `priority:*` maximum.

## Type

| Label              | Use when the PR...                                                        |
| ------------------ | ------------------------------------------------------------------------- |
| `type:feature`     | Adds a new feature or capability                                          |
| `type:bug`         | A bug / unexpected behavior                                         |
| `type:fix`         | Fixes a bug / unexpected behavior                                         |
| `type:hotfix`      | Fixes a critical bug urgently (patch to production)                       |
| `type:enhancement` | Improves an existing feature without adding new capability                |
| `type:refactor`    | Restructures code with no behavior change                                 |
| `type:chore`       | Routine maintenance that isn't a feature or fix                           |
| `type:docs`        | Changes documentation                                                     |
| `type:test`        | Adds or changes tests                                                     |
| `type:ci`          | Changes CI/CD configuration or workflows                                  |
| `type:build`       | Changes build system or tooling                                           |
| `type:dependencies`| Updates dependencies                                                      |
| `type:security`    | Fixes or improves security                                                |
| `type:performance` | Improves performance / reduces resource usage                             |
| `type:style`       | Formatting, whitespace, lint, or code style only                          |

## Status labels

| Label                          | Meaning                                   |
| ------------------------------ | ----------------------------------------- |
| `status:draft`                 | PR is not complete yet                    |
| `status:ready-for-review`      | PR is complete and needs review           |
| `status:in-review`             | Reviewers are actively reviewing          |
| `status:changes-requested`     | Reviewers requested changes               |
| `status:approved`              | PR was approved                           |
| `status:blocked`               | PR is blocked by something                |
| `status:ready-to-merge`        | PR is ready to merge                      |
| `status:merge-conflict`        | PR has merge conflicts                    |

## Priority labels

| Label               | Meaning                                      |
| ------------------- | -------------------------------------------- |
| `priority:critical` | Must be handled as soon as possible          |
| `priority:high`     | High priority but not urgent                 |
| `priority:medium`   | Normal priority                              |
| `priority:low`      | Low priority, can wait                       |
